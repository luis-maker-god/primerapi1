# PrimerAPI - Sistema de Gestión de Clientes

Proyecto desarrollado en **ASP.NET Core Web API** utilizando **Entity Framework Core** y base de datos **MySQL**.

#funciones de la API (`/api/Cliente`)

 Método      funcion               Descripción |
 
GET`     `/api/Cliente`          Obtiene la lista completa de clientes 
GET`     `/api/Cliente/{id}`     Consulta un cliente por su identificador 
POST`    `/api/Cliente`          Registra un nuevo cliente 
PUT`     `/api/Cliente/{id}`     Actualiza un cliente existente 
DELETE`  `/api/Cliente/{id}`     Elimina un cliente
